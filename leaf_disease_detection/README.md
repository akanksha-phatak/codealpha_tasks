# 🌿 Leaf Disease Detection using Deep Learning

## 📌 Overview
This project focuses on detecting and classifying plant leaf diseases using image data. A Convolutional Neural Network (CNN) is used to identify whether a leaf is healthy or affected by a specific disease.

**## 📊 Dataset**
The dataset used is the PlantVillage dataset, which contains:
- 50,000+ leaf images  
- 38 different classes (healthy and diseased)  
- Various crops like tomato, potato, etc.  

****## 🛠️ Technologies Used****
- Python  
- TensorFlow / Keras  
- NumPy  
- Matplotlib  

**## ⚙️ Model Used**
- Convolutional Neural Network (CNN)

**## 🔍 Methodology**
- Image preprocessing using normalization  
- Splitting dataset into training and validation sets  
- Building a CNN model with convolution and pooling layers  
- Training the model on image data  
- Evaluating performance using accuracy metrics  

**## 📈 Results**
- Model successfully learned to classify leaf diseases  
- Achieved good accuracy on validation data  
- Able to distinguish between healthy and infected leaves  

**## 🧠 Key Learnings**
- Understanding of CNN and image-based deep learning  
- Importance of preprocessing in image data  
- Feature extraction through convolutional layers  
- Real-world application of AI in agriculture  

**## 🚀 Applications**
- Early detection of plant diseases  
- Assisting farmers in crop monitoring  
- Improving agricultural productivity  

**## 🌍 Conclusion**
This project demonstrates how deep learning can be effectively used in agriculture to automate disease detection and support data-driven decision-making.
